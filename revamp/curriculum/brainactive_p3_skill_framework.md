# BrainActive P3 High Ability — Skill Framework

A practical curriculum hierarchy derived from the research (CogAT batteries, UK 11+ NVR/VR,
Singapore "thinking skills & heuristics" workbooks, MOE 2026 HAL context). It deliberately
**supersedes** the pilot's five flat categories with a richer, skill-level map.

Legend for ranking columns:
- **Imp** = importance to the product (High/Med/Low)
- **P3** = P3 suitability (High/Med)
- **HA** = high-ability relevance (High/Med)
- **Gen** = question-generation potential (Excellent/Good/Limited)
- **Vis** = requires deterministic visual generator (Y/N)
- **Gd** = generation difficulty (Easy/Med/Hard)

---

## Domain 1 — Numerical Reasoning  (quantitative)
- **1.1 Pattern Discovery** — number sequences, growing differences, alternating rules, interleaved sequences. (Imp High, P3 High, HA High, Gen Excellent, Vis N, Gd Easy)
- **1.2 Numerical Relationships** — number analogies, missing-number relationships, rule inference. (High, High, High, Excellent, N, Easy)
- **1.3 Number Puzzles & Systems** — balances/weights, cryptarithms, small linear systems. (High, Med, High, Good, N, Med)
- **1.4 Quantitative Logic** — comparative/deductive quantity, ordering by value, "who has most". (High, High, High, Good, N, Easy)

## Domain 2 — Logical Reasoning
- **2.1 Deductive Ordering** — rank from comparative clues. (High, High, High, Good, N, Easy)
- **2.2 Constraint & Matching** — seating/scheduling/assignment with constraints. (High, Med, High, Limited, N, Hard)
- **2.3 Conditional Logic** — if-then, must-be-true, contrapositive. (High, Med, High, Good, N, Med)
- **2.4 Classification & Sets** — odd-one-out (numeric/semantic), grouping. (Med, High, Med, Good, N, Easy)
- **2.5 Syllogisms & Inclusion** — transitive set inclusion. (Med, Med, High, Limited, N, Med)

## Domain 3 — Verbal Reasoning
- **3.1 Word Analogies** — function/part/place/category relations. (Med, High, Med, Good, N, Med)
- **3.2 Word Classification / Odd-word** — semantic categories. (Med, High, Med, Good, N, Easy)
- **3.3 Codes & Ciphers** — letter shift, substitution. (Med, High, Med, Excellent, N, Easy)
- **3.4 Anagrams & Letter Sets** — word formation, letter availability. (Med, High, Med, Good, N, Med)
- **3.5 Sentence Logic / Inference** — must-be-true from a rule. (Med, Med, High, Good, N, Med)

## Domain 4 — Visual & Spatial Reasoning
- **4.1 2D Rotation** — mental rotation of shapes. (High, High, High, Excellent, Y, Easy)
- **4.2 Reflection** — mirror across vertical/horizontal axis. (High, High, High, Excellent, Y, Easy)
- **4.3 Nets & Cubes** — which net folds, opposite faces. (High, Med, High, Good, Y, Med)
- **4.4 3D Orientation** — rotated 3D object recognition. (High, Med, High, Good, Y, Hard)
- **4.5 Position & Movement** — grid slides, path tracking. (Med, High, Med, Excellent, Y, Easy)
- **4.6 Shape Transformation** — add/remove side, feature, colour. (High, High, High, Excellent, Y, Easy)
- **4.7 Combining / Hidden Shapes** — decompose or assemble figures. (Med, Med, Med, Good, Y, Med)
- **4.8 Paper Folding** — hole-punch / fold patterns. (Low, Med, Med, Good, Y, Hard)  *(Tier 3)*

## Domain 5 — Pattern & Abstract Reasoning (figural)
- **5.1 Figure Sequences** — shape/colour/position progressions. (High, High, High, Excellent, Y, Easy)
- **5.2 Figure Matrices** — 2×2 and 3×3 completion. (High, High, High, Excellent, Y, Med)
- **5.3 Figure Classification** — odd-one-out via SPONCS. (High, High, High, Excellent, Y, Easy)
- **5.4 Figure Analogies** — transform one figure to another. (High, High, High, Excellent, Y, Easy)
- **5.5 Count/Element Sequences** — dot/group progressions. (Med, High, Med, Excellent, Y, Easy)

## Domain 6 — Problem Solving & Heuristics  (the Singapore "thinking skills" identity)
- **6.1 Working Backwards** — reverse the steps. (High, Med, High, Good, N, Med)
- **6.2 Guess & Check / Assumption** — systematic trial. (High, Med, High, Good, N, Med)
- **6.3 Before–After / Constant Difference** — change comparisons. (Med, Med, Med, Good, N, Med)
- **6.4 Draw a Diagram / Model** — visualise the problem. (High, Med, High, Good, Y, Med)
- **6.5 Make a List / Table** — organise cases. (Med, Med, Med, Good, N, Easy)
- **6.6 Pattern Application** — use a discovered rule to solve. (High, High, High, Good, N, Med)
- **6.7 Multi-step Puzzles** — combine several skills. (High, Med, High, Limited, N, Hard)

## Tier ranking

### Tier 1 — Core (BrainActive must teach these)
1.1 Pattern Discovery · 1.2 Numerical Relationships · 1.4 Quantitative Logic ·
2.1 Deductive Ordering · 2.3 Conditional Logic · 2.2 Constraint & Matching ·
3.1 Word Analogies · 3.3 Codes & Ciphers ·
4.1 2D Rotation · 4.2 Reflection · 4.3 Nets & Cubes · 4.6 Shape Transformation ·
5.1 Figure Sequences · 5.2 Figure Matrices · 5.3 Figure Classification · 5.4 Figure Analogies ·
6.1 Working Backwards · 6.2 Guess & Check · 6.6 Pattern Application

### Tier 2 — Valuable expansion
1.3 Number Puzzles & Systems · 2.4 Classification & Sets · 2.5 Syllogisms ·
3.2 Word Classification · 3.4 Anagrams · 3.5 Sentence Logic ·
4.4 3D Orientation · 4.5 Position & Movement · 4.7 Combining/Hidden ·
5.5 Count/Element Sequences ·
6.3 Before–After · 6.4 Draw a Diagram · 6.5 Make a List · 6.7 Multi-step Puzzles

### Tier 3 — Optional (later / deluxe)
4.8 Paper Folding · (lateral/creative puzzles if we add a "creative" track later)

**Why these boundaries:** every domain above earns its place by mapping to a recognised
reasoning skill AND to a deterministic or well-defined generation path. Nothing is included
merely to inflate the count.
