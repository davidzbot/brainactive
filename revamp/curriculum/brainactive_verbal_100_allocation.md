# BrainActive — Verbal Reasoning allocation within the first 100

> Answer to: *how much of the first 100 should be Verbal?* Recommendation: **~15 questions (15%)**.
> Structure: SOURCE EVIDENCE → ANALYSIS → RECOMMENDATION, with the 10/15/20/25 trade-off.

---

## SOURCE EVIDENCE
- GEP General Ability is split verbal (GA1) vs non-verbal (GA2); verbal includes analogy, anagram, decoding, logic (S1–S8). Verbal is therefore a *characteristic* GEP domain, not a side note.
- CogAT treats the Verbal Battery as one of three equal batteries (S9/S10).
- Current first-100 blueprint allocated **14/100 to Verbal** (3.1×5, 3.2×3, 3.3×3, 3.4×2, 3.5×1).

## ANALYSIS — what "15%" must balance
1. **Differentiation from Math Hero** — Math Hero owns maths drilling. Verbal here must be *language-as-structure* (codes, anagrams, deduction), not comprehension, or we blur the line.
2. **Vocabulary burden** — every extra B-type (sentence completion, rare-word analogy) raises the English-tuition feel and disadvantages kids with weaker vocabulary but strong reasoning. We must cap B.
3. **Generatability** — C-type verbal (codes, letter patterns, anagrams, deduction) is deterministic and AI-friendly; scaling it is low-risk. This argues *for* a healthy verbal share, but built from C not B.
4. **Parent perception** — "Build Thinking Skills for P3 High Ability" reads as reasoning, not English. A very large verbal block (20%+) plus B-heavy items drifts toward English tuition.

## RECOMMENDATION — 15% (≈15 questions), C-weighted

| Skill | Code | Count | Class mix |
|---|---|---|---|
| VR1 Verbal Analogies | 3.1 | 5 | C (with light B avoided) |
| VR2 Classification/Odd-One-Out | 3.2 | 3 | C |
| VR3 Codes & Ciphers | 3.3 | 3 | C |
| VR4 Word Manipulation | 3.4 | 2 | C |
| VR5 Letter & Word Patterns | 3.6 | 1 | C |
| VR6 Sentence Logic & Deduction | 3.5 | 1 | C |
| VR7 Sentence Completion (light, capped) | — | 1 | B (capped) |
| **Total** | | **16** | mostly C |

(16 is the rounded plan; target band **15–16%**. If strict 15, drop VR5 to 0 or VR7 to 0 — but VR4 is mandatory because it is currently absent.)

### Trade-off vs the four options
- **10% (10 Qs):** too thin — under-represents a GEP-characteristic domain and leaves VR4/VR5 barely represented. **Reject.**
- **15% (≈15–16 Qs):** balanced — verbal is clearly a core domain (3rd–4th largest), C-weighted, vocab-capped, generatable. **Recommended.**
- **20% (20 Qs):** stronger GEP signal but pushes vocabulary burden up and risks English-tuition drift; needs more B-items to fill, which we don't want. **Reject unless** we can fill the extra 4–5 entirely with C (codes/anagrams/deduction) — possible but not necessary for v1.
- **25% (25 Qs):** over-weight verbal relative to visual/pattern/logic where school under-teaches and we differentiate. **Reject.**

### Guideline for future scaling (beyond 100)
Keep verbal in the **15–20%** band, always **C-dominated**; let VR3/VR4/VR5 absorb any growth (they are deterministic and vocabulary-free). Never let VR7 (B) exceed ~1 per 100.
