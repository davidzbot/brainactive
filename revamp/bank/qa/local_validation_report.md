1. `g_log_cond` (2.3): explanation hardcoded "19" while the question used a random number 11–29.
   ~15 items regenerated with the correct number.
2. `g_ps_list` (6.5): count used `len(L)**2` instead of `len(L)**len(L)`; 3-letter codes from 3
   letters returned 9 instead of 27. Fixed.
3. `g_log_order` (2.1) second branch: four-runner order was under-determined (d between b and c not
   fixed). Rewritten as a fully-determined chain.
4. `g_log_constraint` (2.2): "who sits second from the left" was not uniquely fixed by the clues.
   Rewritten deterministically.
5. `g_log_class` / `g_ver_class` (2.4 / 3.2): distractor pool contained "whale" (an animal), an
   invalid odd-one-out when the group was animals. Removed.
