# BrainActive — Question Taxonomy (P3 High Ability)

Each archetype lists: **skill tested**, **typical difficulty**, **visual asset required**,
**procedurally generatable**, **common failure modes**, **recommended explanation style**.

Legend — visual: N=no, Y=yes. generative: Y=can be generated by rule, P=partial, N=hand-crafted.

---

## A. Numerical Reasoning
- **A1 Number sequence** — spot additive/geometric/mixed rule. *med*. visual N. gen Y.
  Fail: assumes single rule, misses alternating. Explain: state the rule, show steps.
- **A2 Interleaved sequence** — two rules on odd/even positions. *hard*. N. Y.
  Fail: treats as one sequence. Explain: split positions, give both rules.
- **A3 Number analogy** — relation between pair applied to second pair. *med*. N. Y.
  Fail: picks wrong relation (× vs +). Explain: define relation, apply.
- **A4 Missing-number relationship** — figure/equation rule (e.g. box = f(sides)). *med*. N (text) / Y. 
  Fail: misreads operator. Explain: state formula, substitute.
- **A5 Comparative/deductive quantity** — chain inequalities ("who has most"). *hard*. N. P.
  Fail: sign errors. Explain: assign values step by step.
- **A6 Cryptarithm / systems** — letters as digits, small linear systems. *challenge*. N. P.
  Fail: trial-and-error without checking. Explain: solve algebraically, verify.

## B. Logical Reasoning
- **B1 Deductive ordering** — rank by speed/height from clues. *med*. N. P.
  Fail: reverses a clue. Explain: order list, pick position.
- **B2 Odd-one-out (numeric/semantic)** — one breaks the property. *med*. N. P.
  Fail: picks a different but valid property. Explain: state common property, show exception.
- **B3 Conditional deduction** — modus ponens / modus tollens. *hard*. N. N.
  Fail: affirms the consequent. Explain: state rule + contrapositive.
- **B4 Classification** — category membership. *med*. N. N.
  Fail: over-thinking. Explain: name the category, identify outlier.
- **B5 Constraint matching** — seating/assignment with constraints. *hard*. N. N.
  Fail: ignores a constraint. Explain: enumerate valid arrangements.
- **B6 Syllogism / must-be-true** — transitive / set inclusion. *challenge*. N. N.
  Fail: reverses implication. Explain: chain premises, state conclusion.

## C. Pattern / Sequence (abstract, mostly visual)
- **C1 Figure rotation sequence** — rotate 90°/180° stepwise. *med*. Y. Y.
  Fail: wrong direction. Explain: state turn + direction, show next.
- **C2 Analogy matrix (2×2)** — second = first + change. *hard*. Y. Y.
  Fail: wrong change axis. Explain: describe transformation, apply.
- **C3 Odd-one-out (shapes, SPONCS)** — one figure breaks Shape/Pos/Ori/Num/Colour/Size. *med*. Y. Y.
  Fail: picks wrong dimension. Explain: list common dimension, show exception.
- **C4 Shape analogy (size/feature)** — scale or add feature. *hard*. Y. Y.
  Fail: wrong feature mapped. Explain: map source→target change.
- **C5 Count sequence** — dots/elements increase by rule. *med*. Y. Y.
  Fail: off-by-one. Explain: count each, give rule.
- **C6 Matrix completion (3×3)** — row/column rule. *hard/challenge*. Y. P.
  Fail: fixes on one axis. Explain: derive row rule + column rule, intersect.

## D. Verbal Reasoning
- **D1 Word analogy (function/part)** — e.g. body-part-for-movement. *med*. N. N.
  Fail: picks associational not relational. Explain: name the relation, apply.
- **D2 Word analogy (place/role)** — worker→workplace. *hard*. N. N.
  Fail: picks tool not place. Explain: define relation.
- **D3 Odd-word-out (semantic)** — one not in category. *med*. N. N.
  Fail: picks by superficial trait. Explain: state category.
- **D4 Anagram / letter-set** — can a word be formed / which cannot. *hard*. N. P.
  Fail: misses a needed letter. Explain: list available letters, test each.
- **D5 Decoding / cipher** — letter shift / simple code. *med*. N. Y.
  Fail: shifts wrong way. Explain: show mapping, decode.
- **D6 Sentence logic (must-be-true)** — rule + fact → conclusion. *challenge*. N. N.
  Fail: adds unstated info. Explain: apply given rule only.

## E. Visual / Spatial Reasoning
- **E1 Single-shape rotation** — choose rotated result. *med*. Y. Y.
  Fail: mirror vs rotate confusion. Explain: show rotation steps.
- **E2 Reflection (vertical/horizontal)** — choose mirrored shape. *hard*. Y. Y.
  Fail: rotates instead of reflects. Explain: draw mirror line, map points.
- **E3 3D cube net** — which faces are opposite. *challenge*. Y. P.
  Fail: mis-folds. Explain: fold mentally / label opposite pairs.
- **E4 Shape transformation** — add/remove a side or element each step. *med*. Y. Y.
  Fail: wrong element count. Explain: count elements per step.
- **E5 Position / slide** — element moves by rule across cells. *hard*. Y. Y.
  Fail: wrong direction/step. Explain: track position change.
- **E6 3D orientation** — rotated 3D object recognition. *challenge*. Y. P.
  Fail: confuses faces. Explain: track a marked face through rotation.

## Notes for scaling (30 → 100 → 300)
- **Highly generative (rule-based, safe to auto-generate):** A1, A2, A3, A4, C1–C5, E1, E2, E4, E5, D5. → backbone of volume.
- **Partial (template + curated data):** A5, A6, B1, B2, C6, D4, E3, E6. → need small curated pools.
- **Hand-crafted (quality-critical, low volume):** B3–B6, D1–D3, D6. → author carefully, reuse as templates.
- Visual items should feed a **deterministic SVG/Canvas generator** driven by `visual_spec`
  (rotation angle, reflection axis, grid coords, SPONCS attributes) — never raster images.
